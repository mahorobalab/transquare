配信エリアが、一目でわかる。

Transquare（トランスケア）は、ゲームや作業の邪魔をしない完全クリックスルー対応のデスクトップ赤枠ガイドアプリです。Alt吸着移動・リアルタイムHUD・タスクトレイ常駐に対応。

配信者のための、こだわり抜いた機能

配信画面の調整を極限までシンプル・快適にするためのツールです

🎮

完全クリックスルー

赤枠の内側は完全に透明です。枠の真ん中でゲームプレイやブラウザ操作をしても一切クリックが引っかかりません。

⚡

Altキーでグリッド吸着

Altキーを押しながら移動やリサイズを行うと、10px / 20px / 50px / 100px のグリッド単位でピタッと綺麗に吸着します。

🎯

大きな文字のHUD表示

ドラッグ操作中、画面中央に現在の座標（X / Y）やサイズ（幅×高さ）が大きく表示され、OBSのトランスフォーム設定に迷いません。

📐

角・中央への一括スナップ

メニューから「左上 / 右上 / 画面中央 / 上下左右の中央」へ一発移動。マルチモニター環境の画面端にも自動追従します。

🎨

ホバーでリアルタイムプレビュー

枠線の色、太さ、不透明度（10%〜100%）は、メニューにマウスを乗せるだけでその場でプレビュー変化します。

💾

自動保存 ＆ 4つのプリセット

前回の位置・サイズ・設定を終了時に自動保存。さらにお気に入りの設定を最大4つまでプリセットとして保存・切替可能です。

📥

タスクトレイ常駐 ＆ ワンクリック表示切替

タスクトレイアイコンを左クリックするだけで、枠の「表示 / 非表示」を瞬時にトグル切り替えできます。

🌐

多言語対応（日本語 / English）

OSの言語を自動認識。メニューからいつでも日本語と英語を切り替えることができます。

操作方法

操作 動作
右下の ⚙ ボタン 設定メニューを表示（左クリック・右クリック両対応）
赤枠線上を左ドラッグ 枠を自由に移動（移動ロック解除時）
Alt + 左ドラッグ グリッド吸着移動（指定間隔でスナップ）
右下の四角グリップをドラッグ 枠のサイズ変更（サイズロック解除時、Altで吸着）
トレイアイコン左クリック 枠の表示 / 非表示トグル切り替え
トレイアイコン右クリック 設定メニューを表示（非表示中でも操作可能）
