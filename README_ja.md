## 🎯 Transquare とは？

ゲーム配信や作業配信、画面録画を行う際に、**「ディスプレイのどこが OBS で配信されているか」を一目で把握できる** ガイドフレームアプリです。

配信枠の位置合わせに特化し、作業やゲームの邪魔にならない軽量・快適な操作性を追求しました。

---

## ✨ 主な特徴

- 🎮 **完全クリックスルー（枠内すり抜け操作）**
  - 赤枠の内側は完全にマウス操作が背後に透過するため、ゲームやブラウザ等の操作を一切妨げません。
- 🔒 **誤操作防止（移動・サイズロック）**
  - 起動時は移動とサイズ変更がロックされており、配信中に手が当たって枠がズレる事故を防ぎます。
- ⚡ **Alt キーによるグリッド吸着移動＆リサイズ**
  - `Alt` キーを押しながらドラッグ移動・サイズ変更すると、指定グリッド単位（10px / 20px / 50px / 100px）でカチカチと吸着スナップします。
- 🎯 **大きな文字でのHUDリアルタイム表示**
  - 移動時はディスプレイ左上からの座標 `X / Y`、サイズ変更時は `幅 × 高さ` が画面中央に大きく表示されます（OBSのトランスフォーム設定にそのまま打ち込めます）。
- 📐 **枠位置の一括スナップ配置**
  - 「角（左上 / 右上 / 左下 / 右下）」や「中央（画面中央 / 上・下・左・右）」へワンクリックでスナップ移動可能。マルチモニター環境にも対応。
- 🎨 **リアルタイムプレビュー**
  - 枠線の不透明度（10%〜100%）、太さ（2〜8px）、色（赤/青/緑/黄/白）をメニューにマウスを乗せるだけでその場でプレビュー確認できます。
- 💾 **設定の自動保存 ＆ ユーザープリセット（1〜4）**
  - 最後の位置・サイズ・スタイル設定を自動保存し、次回復元。
  - お好みの位置・サイズを 4 つのプリセットに保存・一発切り替え可能。
- 📥 **タスクトレイ常駐 ＆ タスクバー表示切り替え**
  - タスクトレイアイコンの**左クリックで枠の表示/非表示を瞬時にトグル切り替え**。
- 🌐 **多言語対応（日本語 / English）**
  - OS設定に応じた自動検出、およびメニューからの手動切り替えに対応。

## 🕹 操作方法

| 操作 | 動作 |
| :--- | :--- |
| **右下の ⚙ ボタン** | 設定メニューの表示（左クリック / 右クリック両対応） |
| **赤枠線上を左ドラッグ** | 枠を自由に移動（移動ロック解除時） |
| **`Alt` + 左ドラッグ** | グリッド吸着移動（指定間隔でスナップ） |
| **右下の四角グリップをドラッグ** | 枠のサイズ変更（サイズロック解除時、`Alt` で吸着） |
| **タスクトレイアイコン左クリック** | 枠の表示 / 非表示トグル切り替え |
| **タスクトレイアイコン右クリック** | 設定メニューの表示 |

## 💻 動作要件

- **OS**: Windows 10 / 11 (64-bit)
- **ランタイム**: [.NET 8.0 デスクトップ ランタイム](https://dotnet.microsoft.com/download/dotnet/8.0)（多くの最新Windows環境にはすでにインストールされています）
